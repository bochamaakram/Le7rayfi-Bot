Paramètres de la Voix

Synchronisation HTTPS

Collez l'URL publique d'un fichier JSON autorisé, puis synchronisez.

Fichier local

UTF-8, structure version + items. La base importée reste prioritaire après redémarrage.

Limites contrôlées par l'application

  • 200 fiches maximum.
  • 35 mots-clés maximum par fiche.
  • 180 000 octets maximum pour un fichier importé ou synchronisé.

Le robot est public : ne placez jamais de mot de passe, jeton, données bancaires ou données personnelles dans le JSON ou une carte NFC.

Autorisation du microphone requise

Pour dialoguer vocalement avec Le7rayfi

1

Activez le microphone dans le navigateur

Cliquez sur l'icône de cadenas ou de réglages à gauche de l'adresse web, puis autorisez le « Microphone ».

2

Sur mobile Android

Vérifiez que Chrome a l'autorisation d'accéder au micro dans les Paramètres Android > Applications > Chrome > Autorisations.

3

Alternative écrite immédiate
